# Palette Wheel specification

Palette Wheel is a static web page that builds color schemes on an
artistic (RYB) color wheel, in the style of paletton.com, without ads
and with a copyable export.

## Goals

- Pick a base hue on a red-yellow-blue wheel and get a scheme of one to
  four hues.
- Show five shades of every hue in the scheme.
- Adjust the five shades with five draggable dots inside the wheel.
- Export the palette as a Markdown block that you can paste anywhere.

## Non-goals

- Paletton `uid` URL compatibility. The page has its own URL format.
- A site mock-up preview.
- Per-hue shade sets outside free mode. In a locked scheme all hues
  share one set of five shades.

## Color model

The wheel hue is a value from 0 to 359 on the RYB wheel. The wheel
hue is not the HSV hue. The math is taken from paletton.com's own
`color.wheel` module and reproduces its output bit for bit.

Six anchor colors define the wheel:

| Wheel hue | RGB | Full saturation | Full brightness |
| --- | --- | --- | --- |
| 0 | 255, 0, 0 | 1 | 1 |
| 120 | 255, 255, 0 | 1 | 1 |
| 180 | 0, 255, 0 | 1 | 0.8 |
| 210 | 0, 255, 255 | 1 | 0.6 |
| 255 | 0, 0, 255 | 0.85 | 0.7 |
| 315 | 255, 0, 255 | 1 | 0.65 |

Between two anchors the ratio of the middle RGB channel to the other
two follows a tangent curve, so the visual spacing of hues matches a
painter's wheel. See `frontend/js/color.js` for the segment table.

A shade is a pair of multipliers `[kS, kV]`, each in the range 0-2,
applied to the full saturation and full brightness of the hue. A
multiplier below 1 scales toward 0. A multiplier above 1 moves toward 1.

## Schemes

| Model | Hues |
| --- | --- |
| Mono | base |
| Analog | base, base + angle, base - angle |
| Triad | base, base + 180 + angle, base + 180 - angle |
| Tetrad | base, base + angle, base + 180 + angle, base + 180 |
| Free | base plus any of secondary 1, secondary 2, and complement at fixed hues |

The angle is 5-175 degrees. Mono, analog, and triad can add the
complement (base + 180). When the angle passes 90 degrees, analog and
triad trade places and the angle becomes 180 minus the angle, so a
dragged dot keeps moving with the pointer.

Free mode unlocks the scheme. Dragging the complement dot in any scheme
enters free mode with the current hues. The **Free** button does the
same. In free mode each ring dot moves alone, and dragging the primary
dot turns all hues by the same amount. The angle control is off. Any
scheme button locks the hues back into that scheme and drops the free
hues.

## Inner disc

The five shade dots live in a disc at the center of the wheel. Right is
more saturated, up is brighter. The square of multiplier values is
stretched to fill the disc. The multiplier 1 sits at coordinate 0.5, so
the 0-1 range gets three quarters of each axis.

- Each dot carries a number tag from 0 to 4. The swatches carry the
  same number, and the matching swatch column highlights while the
  pointer rests on or drags a dot.
- Dragging the large dot moves all five dots by the same offset.
- Dragging a small dot moves only that dot.
- Choosing a preset replaces all five values. The preset table comes
  from paletton.com. The **Shades** picker shows every preset as five
  color blocks in the active hue, and the button shows the current
  five shades the same way.

In free mode each color has its own set of five shades. A row of
small chips, one per scheme color, sits in the band above the inner
disc. Click a chip, or a color name in the palette panel, to make that
color active. The active chip gets a gold halo. The disc shows the
active hue and its dots, and the ring dot of the active color gets a
gold halo. The wheel has only one set of five dots at any time. Entering free mode copies the shared set to every color.
Locking back into a scheme keeps the primary set and drops the others.
Presets and the base hex input apply to the active color.

## Preview box

A square above the palette shows the scheme colors together, with the
same geometry as the paletton.com preview. The square has four
quadrants: primary at top left (60 percent wide and tall), secondary 1
at top right, secondary 2 at bottom left, and complement at bottom
right. Each quadrant shows the main shade as its background and the four
other shades as small squares. A quadrant whose hue is not in the
scheme shows the primary.

## Phone layout

At widths of 640 px and below the page is one column in this order:
scheme buttons on one scrolling line, the wheel, the preview box, the
strip, a "Fine-tune" group with hue, angle, base, and shades, and the
per-color rows. The header keeps Export and moves Undo, Redo, Random,
and Reset behind an overflow button. Hit targets on the wheel scale
with the canvas so they stay about the same size under a finger. The
hint text is hidden. Above 640 px the two-panel layout is unchanged.

## Export

The Export button opens a modal with three tabs:

- Markdown: a heading, a scheme summary, an edit link, one table per
  hue with hex, RGB, and HSL, and a fenced CSS block.
- CSS: a `:root` block of custom properties named `--<hue>-<index>`.
- JSON: an object of hue name to an array of five hex strings.

Copy puts the current tab's text on the clipboard. Clicking a swatch
copies that hex.

## URL state

The page keeps its full state in the URL hash, so a URL is a saved
palette:

```
#h=<hue>&m=<model>&c=<0|1>&a=<angle>&p=<preset>&v=<kS,kV;...x5>
```

Free mode adds the three free hues, with `_` for an absent color:

```
&f=<sec1|_>,<sec2|_>,<compl|_>
&w1=<sec1 shades>&w2=<sec2 shades>&wc=<complement shades>
```
